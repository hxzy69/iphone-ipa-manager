# iPhone IPA Manager 0.4.0

A more complete desktop and Discord workflow for managing your IPA files,
accounts, installations and renewals.

## What's new

- **IPA Library:** search actual app names, versions, bundle IDs and filenames;
  see sizes and account assignments without opening each archive manually.
- **Local update suggestions:** the open library checks your folder every 15
  seconds and suggests an unambiguous newer version with the same bundle ID.
  Accepting replaces the account's single IPA assignment.
- **Assignment history and undo:** retain the last 100 changes and restore a
  previous available, unchanged IPA through the normal archive validation path.
- **Guided setup:** walk through choosing a folder, USB pairing, Apple sign-in,
  readiness checks and optional Discord, remote access and automatic renewal.
- **Live progress:** see account stages, elapsed time and recovery guidance.
  Profile refreshes can skip stages; preparation is not shown as an installation.
- **Review changes:** inspect account, app, version, filename and expected
  operation before manual installs, refreshes and queue submissions. Changed
  settings or files require a fresh review. Automatic renewals remain unattended.
- **Discord:** add `/ipa_updates`, `/assignments`, `/progress` and `/setup` with
  private controls, account/history autocomplete and expiring run confirmations.

## Reliability improvements

- Preserve one IPA per account across desktop, Discord and automatic renewal.
- Save assignment history atomically with settings and serialize concurrent saves.
- Reject stale undo operations and recheck reviewed account scope before device work.
- Keep scanning and validation off the GUI thread; clean up closed preview windows.
- Handle malformed IPA manifests with actionable errors.
- Prevent repeated confirmations, misleading cancellation acknowledgements and
  duplicated elapsed-time suffixes.

## Verified

Verified with **579 automated tests**, **28 packaged runtime checks**, embedded
source/native integrity comparison, source privacy validation, and installer,
archive and checksum verification.

The maintainer has personally tested the existing installation and refresh
workflows and reports that they work in their setup.
