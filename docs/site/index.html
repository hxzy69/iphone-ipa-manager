START SIMPLE. BUILD FROM THERE.

Your first install,
in four steps.

You’ll need Windows 11 x64, an iPhone, a USB cable, Apple device software, an Apple account, and an IPA you’re entitled to install.

  1. 01

    Install the manager

    Run the per-user installer, or extract the portable ZIP to a permanent folder. No Python setup is needed.

  2. 02

    Pair your iPhone

    Install Apple’s device software. Connect over USB, unlock the phone, approve Trust This Computer, then choose Connections → Pair connected iPhone.

  3. 03

    Choose your apps

    Select an IPA folder. Add your Apple account, complete verification, and assign an IPA. Save your settings.

  4. 04

    Check, then install

    Run Check setup, then Install apps. After the first USB install works, add Wi-Fi, Discord, or automatic renewal.

INSTALL ≠ REFRESH

Send less.
When less is enough.

A full installation signs and transfers the assigned IPA. A refresh tries to renew the app’s provisioning profile, which can be much smaller than the app itself.

For known profile expiry or rejection, or a pending app change, renewal can use a full-install fallback. Unclear connection failures stop for inspection rather than blindly reinstalling.

Troubleshooting guide ↗
Does this bypass Apple’s sideloading limits?

No. Apple’s provisioning, certificate, device, App ID, and app limits still apply. An account slot in the manager is not an extra allowance from Apple.

What if my PC is off when renewal is due?

Nothing runs while the PC is off, asleep, or signed out. The opt-in scheduler checks at sign-in and every 15 minutes; an overdue renewal waits for a usable connection. Known expired profiles can trigger a full-install fallback. Keep the assigned IPA available.

Can I use any file-transfer app?

Yes. Save completed IPA files into your managed folder using your preferred transfer tool. Choose the file in the desktop app or use Discord’s account and filename autocomplete. This project doesn’t supply IPA downloads.

Do I need Discord or Tailscale?

No. Start with the Windows app and USB. Discord is optional remote control. Tailscale is for the experimental remote connection workflow, not a requirement for USB installation.

Where are credentials and settings stored?

Settings are stored in your Windows user profile. The Discord token uses Windows user encryption; the native backend integrates with Windows Credential Manager for Apple credentials. Prefer local Apple sign-in. Optional Discord login forms are processed by Discord and are not end-to-end encrypted. Read the privacy guide.

Will normal use request administrator permission?

The app’s per-user installer, startup, login, and normal jobs run without launching an elevation prompt. Installing Apple device software or the optional fixed-purpose Wi-Fi bridge is a separate administrator task.

Can it refresh from mobile data after a cold start?

Not reliably. Remote access depends on an established tunnel and services that iOS keeps available. Prepare the tunnel on home Wi-Fi before leaving. Even then, roaming and long-lived connectivity are not guaranteed.

How do I update or report a problem?

Use Help & updates in the desktop app or /updates in Discord. Read the update guide before replacing a running build. For problems, use redacted diagnostics and the issue tracker; never post credentials or pairing records.
