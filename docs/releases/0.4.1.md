# iPhone IPA Manager 0.4.1

The complete 0.4.0 feature set, with the four new workflow commands now available
as buttons in `/panel`:

| Command | Panel button |
| --- | --- |
| `/ipa_updates` | IPA updates |
| `/assignments` | Assignments |
| `/progress` | Progress |
| `/setup` | Guided setup |

The [Discord guide](https://github.com/hxzy69/iphone-ipa-manager/blob/main/docs/DISCORD.md)
explains their actions and autocomplete options. Panel controls retain the same
private owner/server/channel restrictions.

## Verified

Verified with 580 automated tests, 28 packaged runtime checks, embedded-source
integrity, source privacy and release artifact validation. The maintainer has
personally tested the existing install and refresh workflows and reports
successful operation in their setup.
