iPhone IPA Manager · Local preview

Your first installation,
one step at a time.

Start with USB. Add wireless access and Discord once a manual installation works. No Python is needed for the Windows standalone release.

01 / Prepare

Connect and trust your iPhone

Install Apple Devices or iTunes with mobile-device support. Unlock the phone, connect a data cable, and approve Trust This Computer. Confirm Apple's app can see it.

02 / Choose files

Save an IPA folder

Run the setup EXE to install for your Windows user, or keep the portable release in a permanent folder. Browse to a folder containing completed IPA files, then click Save settings. Any transfer app may save files there.

03 / Add an account

Sign in and assign an IPA

Click Select connected iPhone, then Add Apple account. Enter credentials locally, complete Apple verification, and choose the app to assign. Repeat for more accounts.

04 / Install

Check, run, and verify

Use Setup checklist to resolve missing settings, then click Check setup and Install apps. Keep the phone connected. Wait for verified completion and open the installed app. Follow any iOS Developer Mode or developer-trust instructions.

The manager runs in the background. Stop requests cancellation; a device operation may take time to finish. Inspect uncertain results before retrying.

When you're ready for more

FeatureWhat to do
IPA LibraryOpen Accounts & apps → IPA Library to search app names, versions, bundle IDs and filenames. Select a file, choose an account and save its assignment. Metadata is for browsing; saving checks the complete archive.
Update an app versionCopy the completed IPA to the managed folder, refresh the library, choose the new file and save its account assignment. The next install, refresh and renewal use it.
Local Wi-FiEnable Apple Wi-Fi sync while connected by USB. After trusted Remote setup, the manager can select a direct local tunnel without the legacy bridge. The alternative legacy bridge requires separate administrator installation. The manager itself never opens a UAC prompt.
Remote connectionInstall official Tailscale on both devices. On home Wi-Fi, keep USB connected and the phone unlocked, then use Remote setup. Wait for Remote tunnel ready before leaving home.
DiscordUse Discord control to enter your owner/server/channel IDs and bot token locally. Invite the bot with bot + applications.commands scopes and View Channel / Send Messages permissions. Start it and try /panel.
Six-day renewalInstall all assigned apps and verify refresh works first. Enable Automatic renewal, choose the setting, then save. The signed-in PC checks every 15 minutes and catches up when a usable connection returns.

Know the limits

A VPN does not force iOS to expose its installation service. Mobile-only cold starts and uninterrupted roaming are not guaranteed. A lost remote tunnel may need home Wi-Fi to reconnect.

Profile-only renewal is experimental. Known rejection or expiry can trigger a full install, which may transfer a large amount of mobile data. Apple account and device limits still apply.

If something needs attention

For a small report safe to share, use Help & updates → Save support report, or Discord /diagnostics. This reports health flags without accounts, credentials, filenames, device identifiers, network addresses, paths or raw logs.

Check USB trust, available storage, Apple developer requirements and the current connection. Use Open activity logs or Discord /history. Don't publish unreviewed logs: they can contain account emails, device identifiers and paths.

Settings live in %LOCALAPPDATA%\iPhoneIPAManagerCommunity. Keep a private backup. The release contains no saved accounts, token, device pairing or IPA files.

Check for updates

The candidate's Refresh & history shows account outcomes, observed profile expiry, renewal status and the last selected route. Queue network jobs, cancel waiting requests or explicitly retry unfinished accounts. Discord exposes the same controls through /dashboard, /queue and /retry. Failed/interrupted requests pause the queue for review.

Configuration export/restore is available in the dashboard and /backup. Backups include account emails and IPA names, but no passwords, tokens, pairing records or local paths. They are not encrypted; keep them private. Restore previews the account count and requires confirmation.

In the candidate, Download and verify update prepares a separate version folder; Activate prepared update runs its local self-test, requires idle work, restarts components, and migrates existing startup actions. The previous executable is retained for rollback. Discord /update offers the same preparation and confirmation flow. A restarted tunnel may need home Wi-Fi. Version 0.1.2 needs a manual upgrade before these controls are available.

Help & updates → Check for updates and Discord /updates check the official GitHub release. Checks are manual and do not interrupt running jobs. Your version also appears in the desktop title and Discord /status.

Prefer the guided update above. For manual replacement only, update while the iPhone is at home. Let jobs finish, then open Discord control: disable automatic renewal and the remote tunnel, stop the bot, and close the app. Extract the new release into a permanent folder. In its Discord control, turn Windows startup off and back on and restore your background features. Saved settings stay in application data. Keep the previous release folder until the new build works.
